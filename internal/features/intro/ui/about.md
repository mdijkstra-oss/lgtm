# intro

The first screen.

- It opens covered in slop: code of the kind that piles up, and standing out
  of it, each under a marker of its own colour, a handful of the sentences nobody needed, picked afresh
  from `slop.txt` each time. A blade crosses from the left, on a spring, and
  what it passes is clean. Some of what it scrapes off falls away.
- What is left is an empty screen, with the keys at the bottom.
- Space covers the screen and scrapes it again.

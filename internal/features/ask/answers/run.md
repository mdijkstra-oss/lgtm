# What happens when I run strigil?

Plain `strigil` opens the intro page: a full-screen Bubble Tea program that covers the window in slop, waits 0.9 seconds, sends a blade across to scrape it off, and then sits on an empty screen until you quit. No other screen exists behind it yet.

## The clock

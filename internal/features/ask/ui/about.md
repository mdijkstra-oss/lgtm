# ask

Where a document is opened: the frame round a viewer.

- It opens covered in slop, and a blade scrapes it clean (`kit/scrape`).
  What is under it is already the page, and already answers the keys.
- With nothing asked it opens on the palette. What is typed narrows the
  titles; enter opens the chosen document on a tab of its own. ctrl+k
  brings the palette back.
- With a question asked it opens on the model at work. Under the question
  is one line saying what the model is at, with the time it has taken and
  how many calls it has made. Under that, three rows for the end of what
  it is thinking, kept whether it thinks or not, so nothing below moves.
  Then the calls it has made, a row each, the latest last: a done one
  quiet, a refused one with a red cross, the one it waits on lit. When
  there are more than fit, the oldest go.
- Esc stops the model and gives the palette. If the model cannot be asked,
  the line says why, and the keys are the palette's and quit.
- When the document is accepted it opens on a tab, and is in the palette
  from then on.
- A tab a document open, along the top, the open one joined to what is
  below it. `[` and `]` go from tab to tab.
- Under the tabs is the document, drawn by `kit/viewer`, which takes
  every other key.
- The last line says which keys work now: the viewer's, then the frame's.
- A window under 60 by 16 says to make it larger.

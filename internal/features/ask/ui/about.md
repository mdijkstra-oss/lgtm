# ask

Where a document is opened: the frame round a viewer.

- It opens on the palette. What is typed narrows the titles; enter opens
  the chosen document on a tab of its own. ctrl+k brings the palette back.
- A tab a document open, along the top, the open one joined to what is
  below it. `[` and `]` go from tab to tab.
- Under the tabs is the document, drawn by `kit/viewer`, which takes
  every other key.
- The last line says which keys work now: the viewer's, then the frame's.
- A window under 60 by 16 says to make it larger.

# kit

What features share. Nothing here knows a feature.

- `markdown/`: what a document is made of, and reading one from markdown. It
  draws nothing.
- `viewer/`: a document on screen: its text, its blocks, its index.
- `story/`: the format an interface piece uses to show its states, and the
  checks that every piece has them and still looks as recorded.
- `theme/`: every colour strigil draws with, and the check that no colour
  comes from anywhere else.
